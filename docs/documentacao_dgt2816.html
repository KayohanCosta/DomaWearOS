1. Contexto e Objetivo

A empresa fictícia Doma identificou a necessidade de fornecer assistência sonora a funcionários com deficiência auditiva ou visual no ambiente corporativo. O objetivo é desenvolver um aplicativo Wear OS (smartwatch) capaz de usar o áudio como canal principal de comunicação, entregando informações, alertas e feedbacks via fala sintetizada.

Funcionalidades entregues pelo app:
  • 🔊 Leitura de mensagens de texto em voz alta (TTS)
  • 🔔 Reprodução de notificações em áudio
  • ⏰ Lembretes por voz em Português Brasileiro
  • 📡 Detecção automática de saídas de áudio disponíveis
  • 🎧 Suporte a fones Bluetooth A2DP e com fio
  • 🚨 Alertas críticos de segurança (evacuação, incêndio, emergência médica)

3. Microatividade 2 — Implementação

3.1 AudioHelper.kt — Detecção de Saídas de Áudio

Classe utilitária que encapsula toda a lógica de detecção de dispositivos de saída de áudio. O método principal audioOutputAvailable(type) implementa o padrão exigido pela especificação: 

fun audioOutputAvailable(type: Int): Boolean {
    // 1. Verifica se o dispositivo possui saída de áudio
    if (!context.packageManager
            .hasSystemFeature(PackageManager.FEATURE_AUDIO_OUTPUT)) {
        return false
    }
    // 2. Enumera saídas e verifica se o tipo solicitado existe
    return audioManager
        .getDevices(AudioManager.GET_DEVICES_OUTPUTS)
        .any { it.type == type }
}

3.3 AudioDeviceCallback — Detecção Dinâmica em Tempo Real

Detecta conexão/desconexão de fones Bluetooth sem precisar reiniciar o app, atualizando o status na tela automaticamente: 

private val audioDeviceCallback = object : AudioDeviceCallback() {
    override fun onAudioDevicesAdded(
        addedDevices: Array<out AudioDeviceInfo>?
    ) {
        if (audioHelper.isBluetoothHeadsetConnected())
            updateAudioStatus("🎧 Fone Bluetooth conectado!")
    }
    override fun onAudioDevicesRemoved(
        removedDevices: Array<out AudioDeviceInfo>?
    ) {
        if (!audioHelper.isBluetoothHeadsetConnected())
            updateAudioStatus("📢 Bluetooth desconectado.")
    }
}
// Registra no onCreate()
audioManager.registerAudioDeviceCallback(audioDeviceCallback, null)
// Remove no onDestroy() — evita memory leak
audioManager.unregisterAudioDeviceCallback(audioDeviceCallback)

3.4 Intent para Configurações Bluetooth

Redireciona o usuário para parear fones de ouvido assistivos:

val intent = with(Intent(Settings.ACTION_BLUETOOTH_SETTINGS)) {
    addFlags(Intent.FLAG_ACTIVITY_NEW_TASK
          or Intent.FLAG_ACTIVITY_CLEAR_TASK)
    putExtra("EXTRA_CONNECTION_ONLY", true)
    putExtra("EXTRA_CLOSE_ON_CONNECT", true)
    putExtra("android.bluetooth.devicepicker.extra.FILTER_TYPE", 1)
    this
}
startActivity(intent)

3.5 AudioAssistActivity.kt — Text-to-Speech PT-BR

Converte texto em fala em Português Brasileiro, verificando a saída disponível antes de reproduzir:

// Inicializa TTS com PT-BR
tts = TextToSpeech(this, this)

override fun onInit(status: Int) {
    if (status == TextToSpeech.SUCCESS)
        tts.setLanguage(Locale("pt", "BR"))
}

private fun reproduzirAudio(texto: String) {
    when {
        audioHelper.isBluetoothHeadsetConnected() ->
            tvStatus.text = "🎧 Reproduzindo via Bluetooth..."
        audioHelper.isSpeakerAvailable() ->
            tvStatus.text = "📢 Reproduzindo via alto-falante..."
        else -> { /* sem saída — exibe Toast */ return }
    }
    tts.speak(texto, TextToSpeech.QUEUE_FLUSH, null, "doma_tts")
}
